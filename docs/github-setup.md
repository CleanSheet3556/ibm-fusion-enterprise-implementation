# GitHub setup

## Repository

**Name:** `ibm-fusion-enterprise-implementation`

**Description:** Senior Professional-level implementation and demonstration guide for IBM Fusion covering Fusion foundation services, application-consistent backup and restore, regional disaster recovery, migration-based DR, virtual machine management, and multi-cluster hosted cluster management.

## Topics

Recommended:

`ibm-fusion`, `ibm-storage`, `openshift`, `kubernetes`, `redhat`, `openshift-virtualization`, `disaster-recovery`, `backup-restore`, `storage`, `multicluster`, `mce`, `hosted-control-planes`, `lvm`, `infrastructure-architecture`, `gitops`

## Branching

- `main` — reviewed, submission-ready baseline.
- `develop` — integration branch.
- `feature/<capability>` — capability work.
- `fix/<issue>` — corrective changes.

## Pull requests

Require one reviewer for documentation changes and two reviewers for changes affecting production-like manifests/runbooks.

## Tags

Use semantic documentation milestones, for example:

- `v0.1-foundation`
- `v0.2-backup`
- `v0.3-dr`
- `v0.4-vm`
- `v0.5-multicluster`
- `v1.0-submission`

## Badges

Keep badges factual. Do not use badges that imply IBM certification, production deployment or support status unless independently verified.
