# Multicluster Engine

MCE provides Kubernetes/OpenShift cluster lifecycle and multicluster management capabilities.

## Demonstration

1. Prepare the hub/management cluster.
2. Install the supported MCE release.
3. Create/register a managed cluster.
4. Verify cluster visibility and health.
5. Verify credentials and RBAC.
6. Perform a supported lifecycle operation.

## Validation

Use the MCE console and the exact resources generated by the installed version.

Do not hard-code CRD manifests copied from another MCE release.
