# Evidence — multi-cluster-management

Store sanitized evidence for this capability here.

Recommended evidence naming:

`YYYYMMDD_<capability>_<checkpoint>_<description>.<ext>`

Examples:

- `20260922_foundation_operator_status.txt`
- `20260922_backup_restore_success.png`
- `20260922_regional_dr_failover.txt`

Never store credentials, private keys, tokens, kubeconfigs or customer data.
